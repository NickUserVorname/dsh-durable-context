# Historical Versions

This directory contains frozen historical development packages.

Historical artifacts provide provenance and architecture lineage.

They are not automatically current implementations.

## Development stages

- [`v0.1/`](v0.1/) - early project/control-pack lineage
- [`v0.2.x/`](v0.2.x/) - host governance and task/source authority
- [`v0.7.x/`](v0.7.x/) - universal commit/context-management lineage
- [`v0.8.x/`](v0.8.x/) - separation of ordinary answer, investigative state and reclamation

Detailed relationships are documented in:

[`../evidence/provenance/VERSION_LINEAGE.md`](../evidence/provenance/VERSION_LINEAGE.md)

## Publication warning

Historical archives may contain third-party material.

Presence in this staging tree does not itself establish public redistribution rights.

Before making the repository public, verify redistribution rights for every historical binary/archive.

Where rights are unclear, prefer publishing filename, role, hash and provenance rather than republishing the bytes.

See:

[`../LICENSING.md`](../LICENSING.md)
