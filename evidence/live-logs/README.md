# Live Runtime Logs

This directory contains primary runtime qualification and troubleshooting evidence.

The large non-README Markdown file in this directory is the preserved raw/live troubleshooting log.

It should not be rewritten or renamed merely for readability because its current byte identity is recorded in repository provenance.

Treat this directory as LIVE EVIDENCE.

It is not automatically a clean changelog, and individual incidents should retain their original causal uncertainty.
