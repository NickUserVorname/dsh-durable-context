# Full DSH Environment

The complete multi-gigabyte tested/development environment should not be committed directly to GitHub.

This directory is a provenance placeholder.

A public full-environment archive should be considered available only when this file explicitly records:

- external archive link;
- archive filename;
- archive SHA-256;
- freeze date;
- DSH/runtime identity;
- relevant control-package identity;
- sanitization status.

No public full-environment archive is currently implied merely by the existence of this directory.

If a public frozen environment is created, keep the immutable unsanitized original private.

Prefer a scrubbed public archive and explicit provenance metadata.
